Method

From raw data to a browser demo

01

Prepare

Missing values are filled and stress categories are converted into numbers.

02

Train

A Random Forest classifier learns from 80% of the dataset.

03

Evaluate

The remaining 20% is used to measure model accuracy.

04

Run locally

The trained decision trees are exported so predictions can run directly in the browser.
